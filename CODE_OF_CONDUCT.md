# Code of Conduct

We want this project to be welcoming to people with different backgrounds and levels of experience. Be respectful, discuss ideas and evidence rather than attacking people, and assume good intent while remaining open to correction.

Harassment, threats, discriminatory language, and sharing someone else's private information are not acceptable. These expectations apply to issues, pull requests, discussions, and other project spaces.

If you experience or witness a problem, contact the maintainer privately through the contact options on the GitHub profile. Include links or screenshots when practical. The maintainer may remove content, close discussions, or restrict participation to keep the project safe. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
